# Siga a Ordem: Comando-de-Voz-para-Ready-Or-Not---PT-BR
Interface tática de voz em português brasileiro para Ready or Not.

O programa permite executar comandos do jogo por voz, usando reconhecimento offline. A ideia é tornar o controle da equipe mais rápido e natural, sem precisar navegar pelo menu de ordens durante a partida.

Funcionalidades
Reconhecimento de voz em português brasileiro
Funcionamento offline
Comandos para equipe Azul
Comandos para equipe Vermelha
Comandos para toda a equipe
Uso dos comandos padrões do Ready or Not
Seleção de diferentes modelos de reconhecimento de voz
Interface simples voltada para uso durante a partida
Como funciona

O programa escuta o microfone, identifica a frase dita e executa a sequência correspondente dentro do jogo.

Exemplo:

Azul, entrar e limpar.

ou:

Vermelho, entrar com flash.

A intenção é manter o funcionamento próximo ao sistema original de comandos do Ready or Not, apenas substituindo a navegação pelo menu por comandos falados.

Reconhecimento de voz

O reconhecimento é feito localmente no computador.

Depois que o modelo de voz estiver instalado, não é necessário manter conexão com a internet para utilizar o programa.

Existem diferentes modelos disponíveis, permitindo escolher entre menor consumo de recursos ou maior precisão de reconhecimento.

Instalação

Baixe a versão mais recente na página de Releases.

Execute o programa e, na primeira inicialização, escolha o modelo de reconhecimento desejado.

Depois disso:

Configure o microfone.
Abra o Ready or Not.
Inicie o reconhecimento de voz.
Utilize os comandos durante a partida.
